# キートレイル (KeyTrail)

[中文](README.md) · [English](README.en.md)

KeyTrail は、ローカル・オープンソース・オフラインで動作する Windows 用のキーボード使用習慣統計ツールです。「キー時刻・キーコード・イベント種別」だけを記録し、テキスト内容・スクリーンショット・通信は一切扱いません。データはすべて手元の PC にのみ保存されます。

## 機能

- Windows の低レベルフック（`WH_KEYBOARD_LL`）によるバックグラウンド取得。他プロセスへの注入は行いません。
- 計数ルール: 「押下→解放」の 1 往復を 1 回とし、OS の自動リピートは既定で除外。注入イベントは別フラグで記録します。
- 期間表示: 日 / 週 / 月（ローカルタイムゾーン、週は月曜始まり）。
- 4 つの時間帯: 深夜 / 朝 / 昼 / 夜。既定の境界は 0–6 / 6–12 / 12–18 / 18–24 で、設定から変更可能。
- 習慣分析: 24 時間アクティビティ曲線、よく使うキー、修飾キー、ショートカット、キー間隔、連打、短い休止・長い休止。
- 可視化: 等角風のキーボードヒートマップ＋リアルタイムの波紋、24h 曲線、日別トレンド、時間帯シェア。テーマと連動します。
- システム連携: トレイの開始 / 一時停止 / 終了、ログイン時自動起動、閉じる時にトレイへ退避。
- UI 言語: 中文 / English / 日本語 を実行時に切替。ベージュ / ダークのテーマを滑らかに切替。
- データ管理: SQLite WAL、集計 CSV 出力、保持日数による削除、ワンクリック全消去。

## プライバシー境界

- テキスト内容・IME 候補・対象ウィンドウは記録しません。スクリーンショットも通信も行いません。コードにネットワーク API は存在しないため、ご自身で監査できます。
- 詳細データにはキー時刻とキーコードが含まれます。原理的には打鍵列から内容の一部を推定できる可能性があります（同種ツールの宿命です）。パスワードなどの入力時はトレイから一時停止してください。
- 低レベルフックはキーロガーと同じ外見を持つため、セキュリティソフトの誤検知があり得ます。信頼できる入手元から導入し、本リポジトリは誰でも監査・再ビルドできます。
- 権限の境界: 管理者（高整合性）ウィンドウやセキュアデスクトップ（UAC 確認画面）への入力は、通常権限のフックには渡されません。これは Windows の意図的なセキュリティ設計であり、欠損として「修正」するものではありません。

## データとアンインストール

- データ保存先: `%LOCALAPPDATA%\KeyTrail\`
  - `keyboard.db` — メイン DB（WAL モード）
  - `settings.json` — テーマ・言語・自動起動・時間帯境界など
  - `logs\app.log` — ローカル診断ログのみ
- 設定画面の「データフォルダを開く」「統計をすべて削除」で管理できます。CSV 出力は集計データのみです。
- アンインストール: 同梱アンインストーラがプログラム本体と自動起動エントリを削除します。統計 DB はユーザーデータ領域にあり、**既定では保持**されます（長年の習慣データを誤って消さないため）。完全に消す場合はアンインストール後に `%LOCALAPPDATA%\KeyTrail` を手動削除してください。

## 既知の制限

- 管理者ウィンドウとセキュアデスクトップは計数されません（上記参照）。
- キーボード図は ANSI 104 で描画しています。JIS/ISO のキー配置マップは未実装ですが、統計自体はキーボードレイアウトに依存しません。
- 画面ロック中やデスクトップ入力が無い状態では、記録すべき打鍵は当然ありません。

## ビルド

要件: Windows 10/11 x64 と .NET SDK 10。

```powershell
# デバッグビルド
dotnet build KeyTrail.slnx

# セルフコンテナ単一ファイル公開
.\eng\publish.ps1
```

オフライン再現のため、最初に `.\eng\restore-offline.ps1` を実行して NuGet パッケージを `.packages\` にキャッシュし、以後は `eng\publish-offline.ps1` を使用します。

## テスト

- `dotnet run --project tests\SmokeProbe` で指定 DB を読み、フックから DB への計数が正しいか確認できます。
- 長期受入テストの手順は `docs\TESTING.md` を参照してください。

## 構成技術

- C# / .NET 10 LTS + WPF
- Microsoft.Data.Sqlite（SQLite WAL）
- `InputHookService` → 有界 Channel → バッチ書込、`StatisticsService` が表示層へクエリを提供
- テーマと多言語は実行時差替え可能な `ResourceDictionary`。グラフとキーボードは自前描画のコントロールで、イベント駆動アニメーションです。
