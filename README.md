# KeyTrail 键迹

KeyTrail 是一款本地运行、开源、离线的 Windows 键盘使用习惯统计工具。它只记录“按键时间 + 键位 + 事件类型”，不记录输入内容、不截图、不联网，数据只保存在你自己的电脑上。

## 功能

- 后台键盘监听：低层钩子（`WH_KEYBOARD_LL`）跨应用统计，不注入其他进程；
- 计数口径：一次“按下—松开”算一次，默认排除按住不动的系统自动重复；合成输入单独标记；
- 周期视图：日 / 周 / 月，本地时间切分，一周从周一开始；
- 四时段：凌晨 / 早晨 / 中午 / 夜间，边界默认 0–6 / 6–12 / 12–18 / 18–24，可在设置中修改；
- 习惯画像：24 小时曲线、常用键位、修饰键、快捷键组合、击键间隔、连击、短休/长休；
- 可视化：等距伪 3D 键盘热力 + 事件波纹、24h 曲线、每日趋势、四时段占比、主题联动图表；
- 系统集成：开始/暂停/退出托盘菜单、登录自启、关闭窗口最小化到托盘；
- 界面语言：中文 / English / 日本語，运行时切换；浅米色 / 深色主题一键切换；
- 数据管理：SQLite WAL 落盘、CSV 聚合导出、保留期清理、一键清空。

## 隐私边界

- 不记录文本、输入法候选、目标窗口；不截图；不联网。代码中没有网络 API 调用，可在仓库内审计。
- 明细数据包含按键时间戳与键码，理论上可由一段序列反推文本（这是同类工具的共性）。输入密码等敏感内容前，请先通过托盘暂停统计。
- 低层钩子具有“键盘记录器”的外观特征，可能触发安全软件误报。请从可信来源下载，本仓库完整开源，可自行审计构建。
- 系统权限边界：普通权限运行时，管理员窗口和 UAC 安全桌面的输入不会被系统投递给钩子；这是 Windows 的安全设计，不会被当作缺失数据修复。

## 数据与卸载

- 数据目录：`%LOCALAPPDATA%\KeyTrail\`
  - `keyboard.db`：主数据库（WAL 模式）；
  - `settings.json`：主题、语言、自启、时段边界等设置；
  - `logs\app.log`：仅本机诊断日志。
- 可通过设置页“打开数据目录”“清空全部统计”管理；导出 CSV 只包含聚合数据。
- 卸载：使用安装包自带卸载程序即可删除程序文件与开机自启项。统计数据库位于用户数据目录，卸载程序**默认保留**（避免误删多年习惯数据）；如要彻底删除，卸载后在数据目录中手动删除 `%LOCALAPPDATA%\KeyTrail` 即可。

## 已知限制

- 管理员（提升完整性）窗口与安全桌面不计入，见上。
- 当前键盘模型按 ANSI 104 绘制；JIS/ISO 布局的键帽位置映射尚未实现，但所有统计不依赖键盘布局。
- 若屏幕长时间锁定或无桌面输入焦点，自然没有按键事件可记录。

## 构建

前置要求：Windows 10/11 x64，.NET SDK 10。

```powershell
# 调试构建
dotnet build KeyTrail.slnx

# 自包含单文件发布
.\eng\publish.ps1
```

离线复现：首次执行 `.\eng\restore-offline.ps1` 会把 NuGet 包缓存到仓库内 `.packages\`，之后断网执行 `dotnet build KeyTrail.slnx --packages .packages` 或调用 `eng\publish-offline.ps1`。

## 测试

- `dotnet run --project tests\SmokeProbe` 可读取指定数据库，用于人工核对钩子落盘计数；
- 建议的长期验收流程见 `docs\TESTING.md`。

## 技术栈与架构

- C# / .NET 10 LTS + WPF；
- Microsoft.Data.Sqlite（SQLite WAL）；
- 分层：`InputHookService` → 有界 Channel → 批量写库；`StatisticsService` 供视图层查询；
- 主题 / 三语用 ResourceDictionary 动态切换；图表与键盘为自绘控件，动画事件驱动。
