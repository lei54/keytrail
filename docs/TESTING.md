# 验收测试建议

## 计数准确性

1. 设置 `KEYTRAIL_DATA_DIR` 指向测试目录后启动应用（托盘模式）。
2. 用测试脚本发送已知数量的合成按键。
3. 等待 3–5 秒落盘后用 `tests\SmokeProbe` 查询数据库核对。

## 长时间稳定性

- 连续运行 24–72 小时，期间正常打字；
- 每小时检查进程内存是否持续增长（应稳定在数百 MB 内）；
- 强制结束进程后重启，确认最后不足 1 分钟的缓冲可接受且数据库可打开；
- 检查 `%LOCALAPPDATA%\KeyTrail\logs\app.log` 无 ERROR。

## 周期与时段

- 分别生成凌晨/早晨/中午/夜间数据，核对“日/周/月 + 时段过滤”的合计；
- 验证时段边界修改后所有历史查询按新边界重算。

## UI

- 深浅主题切换：无闪烁、无布局跳动，图表与键盘颜色联动；
- 中/英/日切换：无重启即时生效，无文字溢出；
- 关闭窗口进托盘；托盘开始/暂停立即生效；退出后数据库正常关闭。
